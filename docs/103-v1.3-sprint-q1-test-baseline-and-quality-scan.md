Vitest is useful, but adding it without component tests would not improve Q1 acceptance enough to justify extra dependency churn.

## 9. Q2 AiService Split Recommendation

Q2 should split `AiService` incrementally and preserve all v1.2.1 behavior:

1. Add focused regression tests around provider routing, DeepSeek failure with fallback disabled, structured answer behavior, and tool evidence behavior.
2. Extract provider resolution first, preserving `AI_PROVIDER`, `AI_DEEPSEEK_ENABLED`, `AI_FALLBACK_ENABLED`, and no-hidden-fallback semantics.
3. Extract prompt rendering, preserving business-readable Chinese sections and no-fabrication requirements.
4. Extract usage logging, preserving masked-key safety and failed usage logs.
5. Extract conversation/message management, preserving recent context and archive behavior.
6. Extract streaming handling, preserving stop generation and streaming output shape.
7. Extract Function Calling orchestration last, preserving read-only tools, permission checks, no-result messages, evidence summaries, and audit behavior.

Q2 should not introduce DTO type-safety replacement yet. That belongs to Q3 after Q2 has reduced the God Service risk.
