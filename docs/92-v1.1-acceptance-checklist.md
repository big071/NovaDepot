## 6. 已知限制

- Docker Hub 网络异常时，`docker compose build frontend-vue` 可能因基础镜像 token/metadata 拉取超时失败。该问题不属于业务代码问题。
- v1.1 不支持 Excel 导入、导入回滚、批量打印、自动恢复、多租户正式过滤、计费和 DeepSeek 正式生产接入。
- 应收应付为轻量台账，不是完整财务系统。

## 7. 发布结论

NovaDepot v1.1 已通过最终验收，可以作为 v1.1 发布版本交付。若发布环境要求重新构建 Docker 前端镜像，请先确认 Docker Hub 网络可用后补跑：

```powershell
docker compose build frontend-vue
docker compose up -d frontend-vue
```
