# NovaDepot v1.2 Delivery Notes

## Delivered Scope

- Backend migrations through `111-schema-v1.2-sprint4-agent-notification-report.sql`.
- AI Provider, streaming context, Function Calling tools, Agent patrol, notifications, report center, and audit cleanup.
- Frontend pages: `/ai/enterprise`, `/ai/usage-logs`, `/notifications`, `/reports`, `/agent/center`, and existing v1.1 business pages.
- Ops scripts updated for v1.2 reset and data-quality verification.
- Release notes, delivery notes, and acceptance checklist for v1.2.

## Startup

```powershell
docker compose up -d mysql redis backend frontend-vue
```

Open:

- Frontend: `http://localhost:3100`
- Backend API: `http://localhost:18080`
- Swagger: `http://localhost:18080/swagger-ui/index.html`

## Key Configuration

- `AI_PROVIDER=deepseek-chat`
- `AI_DEEPSEEK_ENABLED=false` by default for local no-key operation
- `AI_DEEPSEEK_API_KEY=` empty by default
- `AI_TOOLS_ENABLED=true`
- `APP_AGENT_PATROL_ENABLED=true`
- `APP_AUDIT_CLEANUP_ENABLED=true`
- `APP_AUDIT_RETENTION_DAYS=90`

## Release Follow-up

After final validation and user approval:

1. Merge `develop/v1.2` to `main`.
2. Tag the release as `v1.2`.
3. Push `main` and the tag.

These merge/tag steps are intentionally not automated in Sprint 4 Act unless explicitly requested.
