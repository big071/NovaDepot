# NovaDepot v1.0 AI / Agent 能力说明

## 1. 总体定位

NovaDepot v1.0 的 AI 与 Agent 层定位为"规则驱动 + Mock 兜底 + Provider 可替换"的智能增强层。

- **不依赖付费大模型**：当前所有 AI 能力基于规则匹配与模板生成
- **AI Provider 可插拔**：所有业务代码通过 `AiProvider` 接口调用，切换至 DeepSeek 等付费模型只需修改配置
- **AI 不做独立产品**：AI 能力嵌入仓管、客服、Agent 等业务页面中，不独立为聊天机器人产品

## 2. AI Provider 架构

```
业务层（Controller / Service）
  │
  ▼
AiProviderFactory（根据配置选择 Provider）
  │
  ├── MockAiProvider          # 开发/演示用，返回固定模板
  ├── RuleAiProvider          # ★ 当前默认：匹配 FAQ/SOP/规则生成回复
  ├── DeepSeekChatAiProvider  # [预留] DeepSeek Chat 模型
  ├── DeepSeekReasonerAiProvider  # [预留] DeepSeek Reasoner 模型
  └── PaidAiProvider          # [预留] 付费模型统一封装
```

### 切换付费模型（未来）

仅需修改 `application-docker.yml` 中的一行配置：

```yaml
ai:
  provider: deepseek-chat   # 从 rule 切换为 deepseek-chat
  deepseek:
    api-key: ${DEEPSEEK_API_KEY}
    base-url: https://api.deepseek.com
```

**无需修改任何业务代码。**

## 3. AI 助手（/ai/enterprise）

### 3.1 功能概述

企业级 AI 对话界面，用户可输入自然语言问题获取系统回答。

### 3.2 意图识别

| 意图类型 | 触发关键词示例 | 处理方式 |
|----------|--------------|---------|
| 低库存分析 | "低库存"、"补货"、"快没了"、"不够了" | Agent 执行低库存分析 |
| 补货建议 | "补货建议"、"要补什么"、"采购建议" | Agent 执行补货建议 |
| 异常巡检 | "巡检"、"异常"、"有问题吗"、"检查一下" | Agent 执行异常巡检 |
| 日报生成 | "日报"、"今天做了什么"、"汇报" | 生成业务日报摘要 |
| 入库流程 | "怎么入库"、"入库步骤"、"标准入库" | 匹配 SOP/FAQ 返回流程说明 |
| 常见问题 | "退货怎么处理"、"损坏怎么办"、"联系谁" | 匹配 FAQ 返回回答 |
| 开放问题 | "今天仓库怎么样"、"有什么需要注意的" | 通用业务回答 |

### 3.3 引用来源展示

AI 回复中包含命中知识时，展示引用来源：

```
AI 回答内容：
"标准入库流程包括以下步骤：1. 质检 2. 上架 3. 条码录入 4. 审核 5. 记账"

📎 引用来源：
- FAQ #12 "标准入库流程概述" [查看]
- SOP #3 "日常入库操作规范" [查看]
```

### 3.4 对话管理

- 支持多轮对话（上下文记忆在当前会话中）
- 历史会话列表与回溯
- 消息按会话存储于 `ai_conversations` / `ai_messages`

## 4. Agent 中心（/agent/center）

### 4.1 功能概述

Agent 是自动化任务执行引擎，可通过 AI 助手手动/自动触发，执行数据分析类任务。

### 4.2 内置 Agent 任务

| 任务名 | 功能 | 输出内容 |
|--------|------|---------|
| 低库存分析 | 扫描库存表，按安全线对比，按紧急度排序 | 摘要卡片 + 低库存清单表格 + 补货建议量 |
| 补货建议 | 基于低库存数据 + 历史出库量，生成补货建议 | 推荐补货量、建议采购优先级 |
| 异常巡检 | 扫描库存异常、单据超期、工单积压 | 异常项清单 + 严重度标记 + 建议处理动作 |

├─────────────────────────────────────────────┤

│  螺母 M8   │    30    │   50   │   150      │
│  ...                                      │

### 4.4 Agent 历史

- 每次执行的输入、输出、执行时间均持久化
- 支持按任务类型、时间范围筛选历史
- 历史结果可点开回看完整详情

## 5. 客服 AI 回复

### 5.1 回复模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| AI 建议模式 | AI 填好候选回复，客服确认后手动发送 | 日常客服工作 |
| AI 自动回复 | AI 自动发送回复（需开启） | 非工作时间/简单标准化问题 |

默认使用 **AI 建议模式**。

### 5.2 AI 回复生成流程

```
客户消息 → 提取关键词与意图
         → FAQ 匹配（问题字段相似度）
         → SOP 匹配（适用场景关键词）
         → 规则匹配（优先级、自动回复阈值等）
         → 生成候选回复文本
         → 同时标注引用来源
         → 填充到客服输入框（建议模式）或自动发送
```

### 5.3 人工接管

- AI 自动回复后，标记会话为"AI 已回复"
- 客服可随时接管回复
- 接管记录写入会话历史，可供审计

## 6. AI 能力限制（v1.0）

| 能力 | 状态 | 说明 |
|------|:----:|------|
| 自然语言理解（NLU） | ⚠️ 规则级 | 基于关键词与规则匹配，非深度学习 |
| 多轮对话推理 | ⚠️ 基础 | 上下文在同一会话内保持，不跨会话 |
| 知识检索 | ✅ | 已覆盖 FAQ/SOP/规则 |
| 代码生成 | ❌ | 不在 v1 范围 |
| 数据分析可视化 | ❌ | Agent 有表格输出，但无图表 |
| 外部 API 调用 | ❌ | 不调用第三方服务 |
| DeepSeek 模型 | 🔮 代码已预留 | Provider 抽象已就绪，配置切换即可 |
