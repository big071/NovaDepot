# NovaDepot v1.1 Operational Guides

## CSV Import

- Only UTF-8 CSV is supported.
- The first row must use Chinese column headers.
- Dates use `yyyy-MM-dd`.
- Numbers must not contain thousands separators.
- Invalid rows are skipped; valid rows are imported.
- Duplicate product SKU or partner code rows are skipped and included in the validation report.
- Excel `.xlsx` files and import rollback are not supported in v1.1.

Template and import pages:

- Products: `/wms/products`
- Inventory: `/wms/inventory`
- Partners: `/erp/partners`

## Browser Printing

- Inbound, outbound, and picking documents use browser print and `@media print`.
- Print targets A4 paper.
- Navigation, buttons, and app chrome are hidden in print mode.
- No third-party print library, label printer adapter, custom template designer, or batch print is included in v1.1.

## Backup

PowerShell:

```powershell
./scripts/ops/backup.ps1
```

Shell:

```bash
./scripts/ops/backup.sh
```

Backups are written to `./backups/` as compressed `.sql.gz` files. v1.1 does not implement automatic restore, cloud backup, remote backup, or incremental backup.

## tenant_id Reserve

Sprint 4 only checks that business tables reserve `tenant_id`. It does not enable TenantInterceptor, tenant filtering, login tenant switching, or formal multi-tenant runtime behavior.
