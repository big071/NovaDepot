# v1.4 Demo Data Realism

## Scope

This act replaces placeholder-like seed data with realistic Chinese business demo data. It is limited to seed and baseline data, reset/data-quality references, E2E assertions that depend on fixed demo values, and documentation.

No business logic, API contract, database schema, RBAC semantics, AI provider behavior, frontend page behavior, release branch, or tag is changed.

## Reset

Reset the local demo baseline with:

```powershell
./scripts/ops/reset-commercial-baseline.ps1
```

The reset script reapplies the schema and existing seed layers, then applies the v1.4 demo data realism seed as the final baseline normalization step.

## Acceptance Notes

The seed keeps existing primary keys and core business flow records so existing E2E flows can continue using stable ids. Demo-visible names, codes, remarks, FAQ/SOP text, customer-service tickets, and AI history are rewritten to business-readable Chinese content.
