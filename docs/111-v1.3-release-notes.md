# NovaDepot v1.3 Release Notes

> Version: v1.3
> Branch: `develop/v1.3`
> Release theme: Code Quality & Stability.

## Release Summary

NovaDepot v1.3 is a quality, stability, security, performance, and maintainability release. It does not add new business modules and does not enter v2.0.

The release preserves the v1.1 WMS/ERP/CS/RBAC flows, the v1.2 DeepSeek intelligence core, and the v1.2.1 AI experience hotfix behavior.

## Completed Quality Work

- Established the v1.3 code quality and test baseline.
- Decomposed the backend AI service into focused provider, prompt, usage-log, conversation, message, chat, and stream services.
- Replaced AI provider map-style results with typed internal DTOs while preserving external response shape.
- Optimized CSV import and inventory transaction query paths to reduce N+1 risk.
- Hardened runtime security around JWT secrets, database password configuration, login rate limiting, request size limits, CORS, and secret masking.
- Split the AI frontend page into typed presentation components and reduced explicit `any` usage in `frontend-vue/src` to zero.
- Removed backend `.last("limit ...")` usage and replaced residual limit paths with safer mapper/page query methods.
- Reduced Reports, Agent, and Notification query risks while keeping response keys and page behavior unchanged.
- Split CustomerService and Knowledge backend facades into smaller responsibility services.
- Split selected non-AI frontend Agent and Customer Service page sections into focused components.
- Improved Docker ignore files, backend runtime image selection, and frontend check script coverage.
- Added focused backend and frontend tests for the refactored areas.

## Compatibility

- API paths, request shapes, response shapes, HTTP status semantics, and permissions remain unchanged.
- Database schema and production migrations remain unchanged.
- AI provider behavior, DeepSeek fallback semantics, streaming behavior, Function Calling tools, tool evidence, and key masking remain unchanged.
- Frontend routes, menu permissions, and established page behavior remain unchanged.
- The runtime remains a single-tenant local Docker architecture with `tenant_id` reserved for future work.

## Known Non-Blocking Backlog

- JaCoCo is configured but coverage execution data/gating still needs a dedicated follow-up.
- Checkstyle and SpotBugs are documented as future infrastructure work to avoid broad unrelated churn in v1.3.
- The current npm audit report includes moderate Vite/esbuild development-server advisories; the available automatic fix requires a breaking Vite upgrade and is deferred.
- Redis caching for stable reference data remains a later optimization.
- Formal slow-query/index review remains a later performance task.
- Large report CSV streaming remains a future improvement; v1.3 keeps existing CSV response contracts.
- Some complex bounded `selectList` call sites remain intentionally backlogged where direct replacement could alter behavior.

## Non-Goals

- No v2.0 multi-tenant runtime activation.
- No billing, subscription, SaaS onboarding, RAG, vector database, knowledge graph, multimodal AI, or mobile app.
- No new ERP/WMS/CS business modules.
- No AI write actions or automatic business document operations.
- No API contract, database schema, permission, or AI provider behavior changes.
