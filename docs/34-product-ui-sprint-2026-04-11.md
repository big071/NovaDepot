# NovaDepot 产品级 UI 提升 Sprint（2026-04-11）

## 1. 目标
- 将当前 Vue 前端从“可用后台”提升到“正式 SaaS 产品观感”。
- 限定范围：
  - 仪表盘
  - 商品列表
  - 库存列表
  - 入库页
  - 出库页
  - AI 助手页
  - 客服工作台

## 2. 约束
1. 不影响现有功能。
2. 不改变接口契约。
3. 不做花哨无效动画。
4. 保持 Vue 3 + Tailwind + Naive UI + ECharts 路线。

## 3. 现状问题（本轮输入）
1. 页面头部语义不统一：主操作、上下文、辅助信息分布不一致。
2. 筛选区/操作区/表格容器在不同页面视觉语言不统一。
3. 状态反馈虽已接通，但视觉载体分散，缺少统一状态条与状态芯片。
4. AI 与客服页面有功能闭环，但“工作台化布局”层级感仍不足。

## 4. 设计改造方案

### 4.1 全局样式基线
- 新增统一“产品级”样式原语：
  - 页面 Hero 头部（标题、副标题、辅助状态、主操作）
  - 工具栏容器（筛选、快捷操作、统计芯片）
  - 表格壳层（标题、描述、操作、主体）
  - 会话工作台栅格容器（侧栏、主区、辅助区）
  - 状态芯片/状态提示条（success/info/warning/error 一致表现）

### 4.2 页面层改造
1. 仪表盘：
   - 头部升级为产品化 Hero。
   - KPI 卡片强化层级、可点击感和语义标签。
   - 图表容器头部统一（标题+说明+状态）。
2. 商品/库存：
   - 统一“筛选条 + 操作条 + 表格壳层”结构。
   - 统计信息上浮为状态芯片，列表容器更清晰。
3. 入库/出库：
   - 顶部加入作业上下文与动作区。
   - 单据列表与明细列表均使用一致表格壳层。
   - 状态标签与筛选提示统一化。
4. AI/客服：
   - 统一工作台布局语言。
   - 对话区、会话侧栏、辅助面板视觉层次更明显。
   - 输入区、动作区、状态反馈统一交互表现。

## 6. 验收标准
1. 7 个页面视觉语言统一，头部/筛选/操作/表格容器风格一致。
2. 卡片层级感、状态反馈、可点击反馈明显增强。
3. AI 与客服页面达到现代 SaaS 工作台观感。
4. 功能无回归，接口契约不变。
5. 前端构建通过，可在 Docker 本地运行。

## 7. 开发说明
- 本轮仅做 UI 与交互层改造，不引入新业务字段、不新增后端接口。
- 若设计与实现冲突，以“功能稳定优先、视觉增强次之”为原则。

## 9. UI 改进点清单
1. 统一产品级 Hero 页头：标题、副标题、上下文标签、主操作区一致化。
2. 统一工具栏与状态条：筛选提示、操作提示、统计芯片样式一致。
3. 统一表格壳层：`表头区 + 主体区` 结构，列表信息层次更清晰。
4. KPI 与统计卡层次增强：可点击态、边框反馈、状态标签更明显。
5. 入库/出库页面工作流表达更直观：待审核、可执行动作统计前置展示。
6. AI 工作台升级：会话侧栏与主对话区层次更分明，顶部上下文更完整。
7. 客服工作台升级：会话列表、主消息区、工单/FAQ 辅助区设计语言统一。
8. 状态反馈保持统一：error/success/empty/loading/disabled 在新视觉下仍可清晰识别。
