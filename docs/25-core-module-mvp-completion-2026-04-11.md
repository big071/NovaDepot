# NovaDepot 核心模块最小可用补齐说明（2026-04-11）

## 1. 目标
- 在不做无关重构的前提下，补齐当前核心模块的最小可用缺口。
- 覆盖模块：商品、仓库、库位、库存、入库、出库、AI 助手、客服工作台。

## 2. 本轮识别的未完成项
1. AI 助手缺少会话历史消息接口接通，切换会话后无法从后端回放历史。
2. 库存模块后端已有库存流水接口，前端未展示。
3. 商品模块后端已有详情接口，前端未接通。
4. 仓库模块后端已有详情接口，前端未接通。
5. 入库/出库操作按钮未按单据状态约束，用户可反复触发无效动作。

## 3. 实施策略
1. 后端已具备能力的接口，优先接通前端真实调用。
2. 前端按钮行为统一遵循：
   - 成功：明确提示并刷新 UI。
   - 失败：明确错误提示。
   - 未接通：明确提示“暂未接通”。
3. 保持 Docker Compose 本地可运行，不扩展到无关模块。

## 4. 计划改动
- 后端：
  - AI 模块新增会话消息列表接口：`GET /api/v1/ai/conversations/{id}/messages`。
- 前端：
  - AI 助手页接通会话消息历史加载。
  - 库存页接通库存流水展示。
  - 商品页接通商品详情弹窗。
  - 仓库页接通仓库详情弹窗。
  - 入库/出库页按状态约束动作按钮。

## 5. 验收标准
1. AI 助手支持会话历史回放，发送后可见新消息。
2. 库存页可见真实库存流水列表。
3. 商品与仓库支持详情查看并有异常提示。
4. 入库/出库按钮按状态启用，避免无效动作点击。
5. 变更后 Docker 本地运行与主链路不回归。

## 6. 实施结果
1. 已新增后端接口 `GET /api/v1/ai/conversations/{id}/messages`，按会话返回消息历史。
2. AI 助手页面已接通会话历史加载，切换会话可回放历史消息。
3. 库存页面已接通 `GET /api/v1/inventory/transactions` 并展示最近流水。
4. 商品页面已接通 `GET /api/v1/products/{id}` 详情弹窗。
5. 仓库页面已接通 `GET /api/v1/warehouses/{id}` 详情弹窗。
6. 入库/出库操作按钮已按状态启用：
   - 入库：`DRAFT/SUBMITTED` 可审核，`APPROVED` 可过账。
   - 出库：`DRAFT/SUBMITTED` 可审核，`APPROVED` 可发运。
7. 库位模块对尚未实现的详情能力提供明确占位提示“库位详情暂未接通”。

## 7. 验证结果
- `docker compose up --build -d`：通过。
- 回归接口返回 `code=0`：
  - 商品列表/详情、仓库列表/详情
  - 库存列表/低库存/库存流水
  - 入库/出库列表
  - AI 会话列表、AI 聊天、AI 会话消息
  - 客服会话、客服发消息、FAQ
