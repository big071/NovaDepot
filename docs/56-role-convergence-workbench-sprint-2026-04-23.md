# NovaDepot 角色收敛与工作台重构 Sprint（2026-04-23）

## 1. 目标
本轮聚焦“轻量商用可用性”，将角色、首页、AI/Agent 展示和审核规则从演示形态收敛为小团队可落地形态。

## 2. 新角色体系（前台展示）
1. 管理员（`admin`）
2. 仓储运营（`warehouse_ops`）
3. 客服运营（`cs_ops`）
4. 观察员（`observer`）

说明：
- 底层 `role_code` 与权限点保持兼容。
- 旧角色映射：`WAREHOUSE_MANAGER/WAREHOUSE_OPERATOR -> warehouse_ops`，`CS_AGENT -> cs_ops`，`VIEWER -> observer`。
- 登录页与顶部信息统一展示中文业务角色。

## 3. 首页工作台重构
按角色展示不同标题、说明与快捷任务，不再是同页仅换数据：
- 管理员：首页突出经营总览、审计中心、用户管理、Agent 中心。
- 仓储运营：首页突出低库存、入库、出库、补货建议。
- 客服运营：首页突出会话、工单、FAQ、处理建议/SOP。
- 观察员：首页突出只读总览、库存风险、Agent 历史。

## 4. 去演示味
- 登录页弱化“演示”语义，改为正式产品语言。
- 演示账号入口保留为“可选快捷入口”，不作为主流程。
- 去除技术字段对普通用户的直接暴露（如租户字段输入）。

## 5. AI/Agent 业务入口
在业务页增加一键智能入口：
- 仪表盘：生成运营日报、异常巡检。
- 库存页：低库存分析、补货建议。
- 客服页：处理建议、SOP 建议。

入口行为：
1. 调用 Agent 执行任务。
2. 执行后跳转 Agent Center 并定位 `runId`。
3. 可在 AI 页面与 Agent 历史复盘。

## 6. Agent 结果业务化展示
- 默认展示摘要卡：任务名称、结论摘要、重点指标、建议动作。
- 明细优先表格化展示，字段中文化。
- 原始 JSON 下沉为“技术详情/调试信息”折叠区。

## 7. 审核分离（方案 A）
- 仓储运营：创建、编辑、提交。
- 管理员：审核（approve/unapprove 兜底处理）。
- 观察员：只读。
- 客服运营：不参与仓储审核。

最小实现：
1. 单据保留 `createdBy`。
2. 审核时校验创建人与审核人不能相同。
3. 后端硬性限制：仅管理员可审核入库/出库单。
4. 违规时返回清晰错误提示。

## 8. 验收重点（页面效果）
1. 登录页显示中文业务角色与演示快捷入口，不显示技术化默认字段。
2. 审计中心筛选为“可下拉+可搜索+可清空”，并含时间范围/业务编号/仅失败。
3. 不同角色登录后菜单明显不同，首页标题/快捷任务不同。
4. Agent 参数区按任务动态显示，中文标签和用途说明完整。
5. 客服页能在发送前看到 FAQ、候选回复、工单分类、优先级、SOP 建议。
6. 审核分离规则在后端生效，防止越权与自审。
