# 53. 审计中心详情按钮精度热修（2026-04-23）

## 问题现象
1. 审计中心列表可正常展示。
2. 点击“详情”按钮无有效反馈，详情弹窗无法打开。

## 根因
1. 审计日志主键 `id` 为超大 Long（超过 JavaScript 安全整数范围）。
2. 前端将 `id` 按 `number` 处理，发生精度丢失。
3. 点击详情时请求了错误的 `id`，后端返回“记录不存在”。

## 修复策略（最小改动）
1. 后端审计列表/详情响应中的 `id` 改为字符串输出。
2. 前端审计类型与详情接口参数改为字符串链路。
3. 页面详情按钮按字符串 `id` 调用详情接口。
4. 为兼容已部署前端（仍按 number 传参）的场景，后端详情接口增加“近似 ID 容错回查”。

## 验证
1. 重启后访问审计中心。
2. 点击任意一条“详情”，应弹出详情窗口并显示 diff。
