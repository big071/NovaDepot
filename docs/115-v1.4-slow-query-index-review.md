# NovaDepot v1.4 Slow Query And Index Review

This document records index advice only. v1.4 must not execute DDL, add migrations, or change production schema.

## Candidate SQL For Future Approval

```sql
-- Audit center list and export filters.
CREATE INDEX idx_audit_logs_tenant_time_id
  ON audit_logs (tenant_id, deleted, occurred_at, id);

CREATE INDEX idx_audit_logs_tenant_module_action_time
  ON audit_logs (tenant_id, deleted, module, action, occurred_at);

-- Inventory export and list stability.
CREATE INDEX idx_inventory_tenant_product_warehouse_location
  ON inventory (tenant_id, deleted, product_id, warehouse_id, location_id);

-- Stable reference data lookup and cache warm paths.
CREATE INDEX idx_products_tenant_code_status
  ON products (tenant_id, deleted, product_code, status);

CREATE INDEX idx_warehouses_tenant_code_status
  ON warehouses (tenant_id, deleted, warehouse_code, status);

CREATE INDEX idx_locations_tenant_warehouse_code_status
  ON warehouse_locations (tenant_id, deleted, warehouse_id, location_code, status);

CREATE INDEX idx_partners_tenant_type_code_status
  ON partners (tenant_id, deleted, partner_type, partner_code, status);
```

## Rollback SQL For Future Approval

```sql
DROP INDEX idx_audit_logs_tenant_time_id ON audit_logs;
DROP INDEX idx_audit_logs_tenant_module_action_time ON audit_logs;
DROP INDEX idx_inventory_tenant_product_warehouse_location ON inventory;
DROP INDEX idx_products_tenant_code_status ON products;
DROP INDEX idx_warehouses_tenant_code_status ON warehouses;
DROP INDEX idx_locations_tenant_warehouse_code_status ON warehouse_locations;
DROP INDEX idx_partners_tenant_type_code_status ON partners;
```

## Notes

- Audit log queries currently sort by `occurred_at DESC, id DESC` and filter by tenant, deleted flag, module, action, resource, operator, and date range.
- Inventory export reads the current tenant inventory list.
- Reference data caches reduce repeated reads, but indexes remain useful when caches are cold or Redis is unavailable.
- These indexes require a separate schema-change review before execution.
