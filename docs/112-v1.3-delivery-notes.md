# NovaDepot v1.3 Delivery Notes

## Delivered Scope

v1.3 delivers the Code Quality & Stability phase on top of the v1.2.1 baseline:

- Backend AI module decomposition and AI provider type-safety hardening.
- CSV import, pagination, residual limit-query, Reports, Agent, Notification, CustomerService, and Knowledge cleanup.
- AI and selected non-AI frontend component decomposition with TypeScript cleanup.
- Security, Docker, local developer experience, and static-analysis planning improvements.
- Release notes, delivery notes, and acceptance checklist for v1.3.

No new business feature surface is included.

## Startup

```powershell
docker compose up -d mysql redis backend frontend-vue
```

Open:

- Frontend: `http://localhost:3100`
- Backend API: `http://localhost:18080`
- Swagger: `http://localhost:18080/swagger-ui/index.html`

## Key Configuration

Local no-key operation remains supported:

```env
AI_PROVIDER=deepseek-chat
AI_DEEPSEEK_ENABLED=false
AI_DEEPSEEK_API_KEY=
AI_TOOLS_ENABLED=true
AI_FALLBACK_ENABLED=false
```

For shared or production-like deployments, override secrets through `.env` or host environment variables and never commit real values:

```env
JWT_SECRET=replace-with-at-least-32-random-characters
DB_PASSWORD=replace-with-a-real-database-password
APP_CORS_ALLOWED_ORIGINS=http://localhost:3100,http://127.0.0.1:3100
APP_UPLOAD_MAX_FILE_SIZE=10MB
APP_UPLOAD_MAX_REQUEST_SIZE=10MB
APP_MAX_REQUEST_BODY_BYTES=10485760
```

## Release Follow-Up

After final validation and explicit release approval:

1. Merge `develop/v1.3` into `main`.
2. Push `main`.
3. Tag the release as `v1.3`.
4. Push the `v1.3` tag.

Do not move existing tags `v1.0`, `v1.1`, or `v1.2`.
