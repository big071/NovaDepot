# NovaDepot v1.2 Sprint 3: Function Calling Tool Queries

> Version: v1.2-S3
> Base: `develop/v1.2`
> Theme: read-only AI tool queries with RBAC, audit, and visible evidence

## Goal

Sprint 3 lets the AI assistant call read-only business tools for inventory, inbound, outbound, purchase, sales, tickets, products, partners, and daily operations. The assistant must show tool calls, parameters, result summaries, and evidence in `/ai/enterprise`.

## Strict Scope

Only implement:

- Code-registered `ToolRegistry` and `ToolExecutor`.
- OpenAI-compatible `tools` JSON schema.
- Function Calling orchestration with at most 5 tool calls per user turn.
- Read-only tools: `query_inventory`, `query_inbound`, `query_outbound`, `query_purchase`, `query_sale`, `query_tickets`, `query_product`, `query_partner`, `get_inventory_stats`, `get_daily_report`.
- Tool visualization in the AI page.
- Tool result evidence, business-friendly no-permission/no-result messages, tool audit logs, E2E, and data quality checks.

Do not implement write tools, automatic document creation/approval, inventory updates, customer-service message sending, Agent patrol, notification center, report center, RAG, vector database, knowledge graph, training/fine-tuning, multi-tenant runtime, billing, or v2.0 content.

## Backend Design

- Add `modules.ai.tools` with:
  - `AiToolDefinition`: name, display name, description, required permissions, JSON schema.
  - `AiToolRegistry`: registers the 10 tools and exports schemas for the current user.
  - `AiToolExecutor`: checks permissions, clamps limit to 20, queries by tenant, writes audit/log rows, and returns a normalized result.
  - `AiFunctionCallingOrchestrator`: calls the provider with tools when available, executes returned tool calls, and uses a deterministic mock route when DeepSeek is unavailable.
- Add `ai_tool_call_logs` via migration `110-schema-v1.2-sprint3-function-calling.sql`.
- Keep AI provider abstraction and Sprint 2 streaming/context behavior. No API key or external API failure may cause 500.
- Add config `AI_TOOLS_ENABLED`, default true, so Function Calling can be disabled and Sprint 2 behavior restored.

## Frontend Design

- Extend `/ai/enterprise` to render tool events above the assistant answer.
- Stream events:
  - `tool_start`
  - `tool_result`
  - `tool_error`
  - `tool_limit`
  - `validation_warning`
- Non-streaming response also includes `toolCalls` and `validationWarnings`.
- Display no-permission and no-result states as business messages.

## Acceptance

- 10 read-only tools are registered and executable with RBAC.
- Single turn stops at 5 tool calls.
- Tool calls write `ai_tool_call_logs` and `audit_logs`.
- AI answers cite tool evidence; no-result answers say "未查询到相关数据".
- `/ai/enterprise` shows tool name, parameters, summary, sources, and final answer.
- No real DeepSeek key is required for local startup or verification.
- Existing v1.1 flows and Sprint 2 streaming/context/session features remain green.
