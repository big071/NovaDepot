## 1. Executive Summary

This plan continues v1.3 Code Quality & Stability after Q1-Q6. It does not publish v1.3, enter v2.0, or add business features.

Q1-Q6 completed the first quality-hardening stage:

- Q1: test baseline and code quality scan.
- Q2: `AiService` decomposition.
- Q3: AI provider type safety.
- Q4: CSV import and inventory transaction query performance.
- Q5: security hardening.
- Q6: AI frontend component split and TypeScript cleanup.

The broader v1.3 roadmap still has backend residual risks. Q7-Q9 merge those remaining backend cleanup themes into one bounded plan:

- Q7: Limit Query and Residual Baseline Cleanup.
- Q8: ReportsService Query and Export Cleanup.
- Q9: Agent / Notification Service Cleanup.

The implementation must preserve all v1.1, v1.2, and v1.2.1 released behavior.

## 5. Q7 Plan: Limit Query and Residual Baseline Cleanup

Q7 focuses on residual query risk and establishes a post-Q1-Q6 backend query baseline.

### Q7 Tasks

1. Scan the full repository for `.last("limit ...")`.
2. Scan string-concatenated `limit` and `order by ... limit` patterns.
3. Scan unpaged `selectList(...)` residual call sites.
4. Classify long-list risk as P0/P1/P2.
5. Replace safely bounded `.last("limit ...")` call sites with parameterized mapper methods or MyBatis-Plus `Page`.
6. Register complex query sites as backlog instead of forcing risky rewrites.
7. Re-scan `.last`, `selectList`, service size, and test counts after implementation.

### Q7 Priority

| Priority | Definition | Example |
|---|---|---|
| P0 | String-concatenated limit or externally influenced pagination limit | `limit " + offset + "," + safePageSize` |
| P1 | Fixed limit that can be moved to a parameterized mapper or `Page` safely | `limit 50`, `limit 100`, `limit 200` |
| P2 | Query requires broader service redesign or public contract review | full-array list endpoints and complex report aggregations |

### Q7 Allowed Files

- Mapper interfaces for targeted query methods.
- Services containing safe `.last("limit ...")` replacements.
- Focused backend tests.
- This plan and docs index.

### Q7 Implemented Result

- Replaced all full-repository `.last("limit ...")` usages with mapper-level parameterized methods.
- Replaced string-concatenated pagination limit usage in Agent, Notifications, Audit, Customer Service, and AI usage logs.
- Kept public API response shapes unchanged.
- Added focused tests in `BackendResidualCleanupTest`.
