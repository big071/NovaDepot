# NovaDepot Vue 前端视觉与交互优化说明（2026-04-11）

## 1. 目标
- 在不影响现有功能稳定性的前提下，提升核心页面视觉层次与交互质感。
- 优先优化结构、留白、卡片、状态反馈，不引入花哨动画。

## 2. 本轮范围
- 仪表盘
- 商品列表
- 库存列表
- AI 助手页
- 智能客服工作台

## 3. 优化原则
1. 视觉层级清晰：页面标题区、统计区、数据区、操作区主次分明。
2. 交互反馈明确：hover/focus/active 在关键按钮与可点击项上可感知。
3. 信息可读优先：不牺牲数据密度和业务可操作性。
4. 功能零回归：保持现有接口与交互行为不变。

## 4. 计划改动
1. 全局样式层：新增统一卡片、标题、对话面板、焦点高亮等样式基线。
2. 仪表盘：强化 KPI 卡层次与图表区头部信息表达。
3. 商品/库存：优化列表页面信息结构，增强表格容器与工具区可读性。
4. AI/客服：优化会话列表、消息区、输入区视觉层次，贴近成熟 SaaS 工作台。

## 5. 验收标准
1. 卡片层次感更强，统计区具备更明确视觉权重。
2. 图表与数据区更现代，且无功能退化。
3. hover/focus/active 反馈明显。
4. AI 与客服对话区视觉与操作体验更接近成熟 SaaS。
5. Docker 构建与运行通过。

## 6. 实施结果
1. 新增全局 UI 基线样式：页面头部、卡片面板、KPI 卡、表格容器、会话列表项、对话输入区、焦点高亮。
2. 仪表盘：
   - 头部改为结构化卡片样式。
   - KPI 卡增加标签语义与层次化视觉。
   - 图表区增加标题与辅助说明，信息表达更完整。
3. 商品列表：
   - 新增“刷新 + 新增”双操作区。
   - 列表卡片增加数据概览（记录数）与统一表格视觉。
   - 详情操作按钮焦点反馈增强。
4. 库存列表：
   - 增加库存记录数/低库存项/流水数量三张统计卡。
   - 库存、预警、流水三区块采用统一现代化面板。
5. AI 助手：
   - 会话列表样式升级，突出 active 状态与 provider 标签。
   - 对话区与输入区分层，更接近成熟 SaaS 对话体验。
6. 智能客服工作台：
   - 会话队列、消息区、快捷操作与 FAQ 统一为分层面板。
   - 消息气泡与会话状态标签可读性增强，输入区反馈更明确。

## 7. 验证结果
- `docker compose up --build -d`：通过。
- 核心接口回归：`dashboard/products/inventory/ai/customer-service` 均返回 `code=0`。
- 本轮仅做前端视觉与交互层优化，未改后端技术栈与业务接口契约。
