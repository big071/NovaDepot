## 1. 核心功能

### 仓储运营
- **库存总览**：库存列表、库存明细、库存流水
- **低库存预警**：库存低于安全线自动标记，支持阈值配置
- **入库管理**：创建 → 提交 → 审核 → 执行（过账），完整状态机
- **出库管理**：创建 → 提交 → 审核 → 发运，库存不足阻止发运
- **库存事务追踪**：每笔变动记录来源单据类型与编号

### 客服与工单
- **客服会话**：多会话管理、消息时间线
- **AI 建议/自动回复**：基于 FAQ/规则匹配的回复建议与自动回复
- **工单管理**：创建、状态流转、责任人指派、备注
- **工单处理历史**：时间线查看状态变更、责任人变更
- **知识沉淀**：从工单直接生成 FAQ/SOP 草稿

### 知识库
- **FAQ 维护**：新增、编辑、启用/停用、草稿→确认状态流转
- **SOP 维护**：新增、编辑、启用/停用、草稿→确认状态流转
- **规则配置**：管理员修改低库存阈值等业务规则，非管理员只读

### AI 助手与 Agent
- **AI 对话**：企业级对话界面，历史消息可回溯
- **意图识别**：任务型问题自动触发 Agent 执行
- **知识引用**：命中 FAQ/SOP 时展示引用来源
- **Agent 任务**：低库存分析、补货建议、异常巡检
- **业务化结果**：摘要卡片 + 表格明细 + 执行依据 + 建议动作

### 审计中心
- 知识变更、单据操作、客服操作全部记录审计日志
- 按模块/动作/资源类型/操作人多维筛选
- 仅管理员可访问

## 2. 角色权限 (RBAC)

| 角色 | 核心权限 |
|------|---------|
| **admin** (管理员) | 全部权限：仓储、客服、知识库、审计、规则配置、Agent |
| **warehouse** (仓储运营) | 入库/出库/库存操作、查看 AI/Agent 结果 |
| **cs** (客服运营) | 客服会话、工单管理、知识库查询 |
| **observer** (观察员) | 只读：库存概览、AI 对话、知识库查看 |

## 3. Docker 部署

- 单命令启动：`docker compose up -d`
- 4 个服务容器：MySQL 8、Redis、Spring Boot 后端、Vue 前端 (nginx)
- 前端：http://localhost:3100
- 后端 API：http://localhost:18080
- Swagger：http://localhost:18080/swagger-ui/index.html

## 5. 已知限制

| 限制 | 说明 |
|------|------|
| 单租户 | 无租户隔离，所有数据共享同一数据库 |
| Mock AI | AI 层使用 Mock + Rule Provider，未接入付费 API |
| 无 ERP 三链 | 采购/销售/财务模块未实现 |
| 无 RAG | 未使用向量数据库，知识匹配基于 SQL 规则 |
| 无工作流引擎 | 使用简单状态机，无复杂 BPM |
| 无移动端 | 仅桌面 Web 端 |
| 无计费系统 | 未实现商用计费 |
