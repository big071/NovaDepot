# NovaDepot v1.4 Release Notes

Version: NovaDepot v1.4

Codename: Ops & Admin Readiness

Based on: v1.3 Code Quality & Stability

## Core Outcomes

1. Completed role and permission management on top of the existing RBAC tables.
2. Added Redis cache-aside support for stable reference data.
3. Added slow-query and index recommendation documentation.
4. Streamed inventory CSV export and added audit-log CSV export.
5. Added a lightweight health endpoint and Docker backend healthcheck.
6. Extended v1.4 E2E coverage for role management, permission control, CSV export, and login rate limiting.
7. Confirmed residual cleanup for backend `System.out.println` and frontend production `console.log/debug/info`.

## Explicit Non-Goals

1. No v2.0 work.
2. No multi-tenant runtime activation.
3. No billing.
4. No RAG, vector database, or multimodal AI.
5. No production database schema change.
6. No index DDL execution.

## Backlog

1. Index SQL requires a separate future schema-change approval.
2. Deeper CI and static-analysis hardening remain future work.
3. npm audit moderate dependency upgrades require separate assessment; no `npm audit fix` was run in v1.4.
4. v2.0 multi-tenant SaaS planning remains the next planning track after v1.4 release closure.
