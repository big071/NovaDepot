# v1.2.1 AI Experience Hotfix

## Scope

This hotfix is limited to the v1.2 AI assistant experience. It does not change the v1.2 tag and does not introduce v2.0 capabilities such as RAG, vector databases, knowledge graphs, multimodal input, semantic cache, multi-tenancy, or billing.

## Goals

- Render AI replies as readable business assistant output instead of raw Markdown text.
- Guide DeepSeek to answer in Chinese with stable sections: current conclusion, key risks, recommended actions, data basis, and next executable step.
- Ensure read-only tool query results are fused into the final answer.
- Make DeepSeek failures explicit when fallback is disabled.
- Show AI provider and fallback status in the AI operations UI.

## Design Notes

- The backend keeps the existing provider abstraction. `rule` is used only when configured as the provider or when fallback is explicitly enabled.
- Tool calls remain read-only and permission checked. Final answers expose business display names and result summaries, not raw function names.
- The frontend renders structured sections, highlights important quantities/status/risk words, and keeps tool evidence behind a collapsible area.
- Prompt wording forbids fabricated inventory, amount, order number, and status values. If no tool data is available, the answer must say that no related data was found.
- Both streaming and non-streaming chat paths attach available read-only tools to DeepSeek context, then replace the final assistant answer with a tool-result-based business summary when tools run.
- DeepSeek Chat and Reasoner failures write unsuccessful usage logs and return explicit errors when fallback is disabled.

## Acceptance

- `/ai/enterprise` no longer displays headings, bold marks, inline code marks, or lists as a raw Markdown blob.
- Tool-backed answers say the system has already queried data and summarize the returned facts.
- DeepSeek failure with `AI_PROVIDER=deepseek-chat`, `AI_DEEPSEEK_ENABLED=true`, and `AI_FALLBACK_ENABLED=false` returns a failed assistant message and usage log with `success=0` and an error code.
- AI usage/config UI shows active provider, model, DeepSeek status, and fallback status.
