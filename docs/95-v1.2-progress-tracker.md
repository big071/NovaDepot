## Sprint 1 Acceptance Notes

- DeepSeek is explicit opt-in via `AI_DEEPSEEK_ENABLED=true` plus `AI_DEEPSEEK_API_KEY`.
- Without a real API key, validation is limited to the RuleProvider/MockProvider degradation chain and configuration safety.
- API keys are read from environment configuration and only returned to the frontend as masked status.
- `ai_usage_logs` records DeepSeek success and DeepSeek degradation events with provider, success flag, latency, and error reason.
