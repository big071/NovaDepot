# NovaDepot v1.0 FAQ / SOP / 规则配置说明

## 1. 概述

NovaDepot v1.0 将 FAQ（常见问题）、SOP（标准操作流程）和业务规则从代码中抽离为 **可维护的知识资产**。这些知识被 AI 助手、客服回复、Agent 分析统一引用，形成持续迭代的知识底座。

## 2. FAQ（常见问题）

### 2.1 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | 文本 | 问题内容（关键词匹配核心字段） |
| `answer` | 文本 | 标准回答 |
| `category` | 枚举 | 分类：入库/出库/库存/退货/系统/其他 |
| `scene` | 文本 | 适用场景描述 |
| `priority` | 整数 | 优先级（数字越小越优先匹配） |
| `status` | 枚举 | 状态：草稿 / 已启用 / 已停用 |
| `source_ticket_id` | 外键 | 来源工单（从工单沉淀时记录） |
| `created_by` | 外键 | 创建人 |
| `updated_by` | 外键 | 最后更新人 |

### 2.2 生命周期

```
[新建草稿] ──确认──→ [已启用] ──停用──→ [已停用]
     │                    │
     │ 编辑后仍为草稿     │ 重新启用
     └────────────────────┘
```

- **草稿**：未生效，不被 AI/客服引用
- **已启用**：正常生效，可被 AI/客服匹配引用
- **已停用**：不再生效，但保留记录供审计

### 2.3 操作权限

| 操作 | admin | warehouse | cs | observer |
|------|:-----:|:---------:|:--:|:--------:|
| 查看 FAQ | ✅ | ✅ | ✅ | ✅ |
| 新建 FAQ | ✅ | ❌ | ✅ | ❌ |
| 编辑 FAQ | ✅ | ❌ | ✅ | ❌ |
| 启用/停用 | ✅ | ❌ | ✅ | ❌ |
| 草稿→确认 | ✅ | ❌ | ✅ | ❌ |

### 2.4 引用来源展示

当 AI 回复或客服建议命中 FAQ 时，前端展示：

> 📎 引用来源：FAQ #12 "标准入库流程概述" [查看详情]

## 3. SOP（标准操作流程）

### 3.1 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | 文本 | SOP 标题/主题 |
| `scene` | 文本 | 适用场景描述（关键词匹配） |
| `steps` | 文本 | 标准操作步骤（换行分隔） |
| `risks` | 文本 | 风险点/注意事项 |
| `check_points` | 文本 | 复核项/检查点 |
| `status` | 枚举 | 状态：草稿 / 已启用 / 已停用 |
| `source_ticket_id` | 外键 | 来源工单 |
| `created_by` | 外键 | 创建人 |

### 3.2 生命周期

与 FAQ 相同：草稿 → 确认 → 已启用 ↔ 已停用

### 3.3 操作权限

| 操作 | admin | warehouse | cs | observer |
|------|:-----:|:---------:|:--:|:--------:|
| 查看 SOP | ✅ | ✅ | ✅ | ✅ |
| 新建 SOP | ✅ | ❌ | ✅ | ❌ |
| 编辑 SOP | ✅ | ❌ | ✅ | ❌ |
| 启用/停用 | ✅ | ❌ | ✅ | ❌ |
| 草稿→确认 | ✅ | ❌ | ✅ | ❌ |

### 3.4 AI 引用

SOP 在以下场景被引用：
- AI 助手回答流程类问题（如"怎么入库"）
- 客服回复时推荐操作步骤
- Agent 执行任务时作为执行依据

## 4. 规则配置

### 4.1 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `rule_key` | 文本 | 规则键（如 `low_stock_threshold`） |
| `rule_value` | 文本 | 规则值 |
| `rule_type` | 枚举 | 类型：阈值 / 开关 / 优先级 / 分类 |
| `description` | 文本 | 规则说明 |
| `is_editable` | 布尔 | 是否允许编辑 |
| `updated_by` | 外键 | 最后更新人 |

### 4.2 当前可配置规则

| 规则键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `low_stock_threshold` | 阈值 | 50 | 低库存安全线 |
| `critical_stock_threshold` | 阈值 | 10 | 紧急缺货线 |
| `auto_reply_priority_threshold` | 优先级 | 3 | 自动回复的最小匹配优先级 |
| `ticket_auto_close_days` | 阈值 | 7 | 工单自动关闭天数 |
| `knowledge_draft_requires_review` | 开关 | true | 草稿是否需审核后生效 |

### 4.3 严格权限控制

**仅管理员可以修改规则配置。**

| 操作 | admin | warehouse | cs | observer |
|------|:-----:|:---------:|:--:|:--------:|
| 查看规则 | ✅ | ❌ | ✅ | ✅ |
| 修改规则 | ✅ | ❌ | ❌ | ❌ |

- 非管理员：页面按钮置灰 + tooltip "仅管理员可修改业务规则"
- 后端 API：`@RequirePermission("rule:manage")` AOP 校验，无权限返回 403

## 5. 知识沉淀闭环

### 5.1 从工单沉淀 FAQ

```
客服处理工单 → 发现高频/典型问题
  → 点击"沉淀为 FAQ"
  → 自动填充：
      - question：客户原始问题
      - category：根据工单分类自动匹配
      - scene：工单场景
      - source_ticket_id：来源工单 ID
  → 客服编辑 answer 和 priority
  → 保存为草稿
  → 确认 → 已启用，正式生效
```

### 5.2 从工单沉淀 SOP

```
客服处理工单 → 总结出标准处理流程
  → 点击"沉淀为 SOP"
  → 自动填充：
      - title：工单主题
      - scene：适用场景
      - source_ticket_id：来源工单 ID
  → 客服填充 steps / risks / check_points
  → 保存为草稿
  → 确认 → 已启用
```

### 5.3 知识生效

- 草稿阶段：不参与 AI 匹配和客服建议
- 确认后：立即进入知识库匹配范围
- 停用：立即退出匹配范围，但保留历史记录

## 6. 审计覆盖

知识库所有变更操作均自动记录审计日志：

| 操作 | 审计内容 |
|------|---------|
| FAQ 新增 | 记录 FAQ ID + 问题摘要 + 创建人 |
| FAQ 编辑 | 记录变更前/后差异 + 编辑人 |
| FAQ 启用/停用 | 记录状态变更 + 操作人 |
| FAQ 草稿确认 | 记录确认动作 + 确认人 |
| SOP 新增 | 记录 SOP ID + 标题 + 创建人 |
| SOP 编辑 | 记录变更前后 + 编辑人 |
| 规则修改 | 记录规则 key + 旧值 → 新值 + 修改人 |

审计中心可按模块 `knowledge` 筛选所有知识变更记录。

## 7. 页面入口

| 页面 | 路由 | 说明 |
|------|------|------|
| 客服工作台 | `/cs/workspace` | 含知识维护入口（FAQ/SOP 列表） |
| FAQ 列表 | 客服工作台内 | 查看/编辑/启用/停用 FAQ |
| SOP 列表 | 客服工作台内 | 查看/编辑/启用/停用 SOP |
| 规则配置 | 系统设置或知识维护内 | 仅管理员可见编辑态 |
| 审计中心 | `/system/audit-center` | 按模块 knowledge 查看变更历史 |
