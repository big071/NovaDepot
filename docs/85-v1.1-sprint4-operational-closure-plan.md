# NovaDepot v1.1 Sprint 4 Plan: Operational Closure

## Goal

Sprint 4 closes v1.1 with operational essentials for real local use:

- product, inventory, and partner CSV imports
- CSV templates and row-level validation reports
- browser print views for inbound, outbound, and picking documents
- database backup scripts and backup records
- tenant_id reserve consistency checks without enabling tenant filtering
- data quality, E2E regression, and final v1.1 documentation

## Strict Scope

- CSV only, UTF-8 only, Chinese header row, no Excel import.
- Duplicate SKU or business code rows are skipped and reported by default.
- Valid rows import even when invalid rows exist.
- Inventory import writes `inventory_transactions` with `biz_type = INVENTORY_IMPORT`.
- Print uses browser `window.print()` and `@media print` CSS only.
- Backups use `mysqldump` plus gzip into `./backups/`.
- tenant_id work is reserve and consistency checking only. No TenantInterceptor, no tenant filtering, and no login changes.

## Out Of Scope

- Excel `.xlsx`, export reports, import rollback, overwrite import mode, custom template designer, batch print, label printers.
- Automatic restore, cloud backup, remote backup, incremental backup.
- DeepSeek production integration, multi-tenant runtime, billing, v1.2/v2.0 features.
- Purchase returns, sales returns, invoices, contracts, quotes, inquiries, or price comparison.
- Rework of stable v1.0, Sprint 1, Sprint 2, or Sprint 3 flows.

## Implementation Plan

1. Finish docs first and update the v1.1 progress tracker.
2. Normalize product and inventory CSV import behavior and add partner CSV import.
3. Add CSV templates, error report download, import audit events, and sample CSV files.
4. Add print CSS and print actions for inbound, outbound, and picking documents.
5. Add backup records, backup module, backup scripts, and admin backup page.
6. Add tenant_id consistency checks to data quality.
7. Add Sprint 4 E2E coverage and run the full v1.1 regression suite.

## Acceptance

- CSV templates download and use Chinese UTF-8 headers.
- Mixed valid/invalid CSV imports valid rows and produces field-level error reports for bad rows.
- Product/partner duplicate codes are skipped and reported.
- Inventory CSV import creates inventory transactions.
- Inbound, outbound, and picking print views contain required business fields and hide app chrome in print mode.
- Backup script creates `.sql.gz`; admin can list and trigger backups; non-admin cannot.
- tenant_id consistency check passes without enabling runtime multi-tenancy.
- v1.0 WMS/CS/AI/Agent/knowledge/audit, Sprint 1 ERP, Sprint 2 WMS linkage, and Sprint 3 finance/stocktake regressions remain green.
