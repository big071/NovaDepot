# NovaDepot Phase 4：四套场景截图/录屏基线（2026-04-22）

## 1. 目标
为 Phase 3 四套业务场景建立固定截图与录屏节点基线，确保每次交付演示可重复、可对比、可验收。

## 2. 使用规则
1. 每套场景固定 3-5 个截图点。
2. 截图命名规范：`SCN-<场景编号>-<序号>-<节点名>.png`。
3. 录屏命名规范：`SCN-<场景编号>-demo-YYYYMMDD.mp4`。
4. 每次发布后至少更新一轮截图（关键节点不允许缺失）。

## 8. 新手模式流程映射（对齐 2026-04-22 Sprint）
1. 首页入口顺序建议：
   1. 我要看今日经营情况（先看全局）
   2. 我要看低库存（先识别风险）
   3. 我要入库（补货）
   4. 我要出库（履约）
   5. 我要处理客服工单（闭环服务）
2. 场景与首页入口映射：
   1. 场景A（入库链路）对应“我要入库”。
   2. 场景B（出库+低库存）对应“我要出库”“我要看低库存”。
   3. 场景C（客服链路）对应“我要处理客服工单”。
   4. 场景D（经营+AI）对应“我要看今日经营情况”。
3. 录屏开场建议（统一脚本）：
   1. 先展示首页快捷任务区。
   2. 说明当前目标与角色。
   3. 进入对应场景页执行步骤。
4. 验收要点补充：
   1. 截图与录屏中应包含页面内新手说明文案。
   2. 空态页面需展示“下一步建议”后再继续录制。
